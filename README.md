# TikTok Analytics Scraper

Automation tool to collect TikTok video metrics and store them in Google Sheets.

## Features
- Scrape Like, Comment, Save, Share
- Extract View Count from TikTok JSON
- Auto update Google Sheets
- Retry system for API limits
- Skip processed rows

## Tech Stack
- Python
- Selenium
- Google Sheets API
- Regex

## Use Case
Used to automate TikTok campaign reporting and analytics tracking.
